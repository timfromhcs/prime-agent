# Vision Skill

Use this skill to inspect image artifacts, extract text through OCR, analyze UI layout, and provide structured critiques for image generation and editing tasks.

## Rules
1. Never guess image content without running VLM inference.
2. For OCR, extract verbatim text strings.
3. For visual QA, check whether required elements, colors, and compositions are present.
