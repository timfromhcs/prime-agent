# Coding Skill

Use this skill to inspect, edit, test, diagnose, and verify code within the workspace.

## Rules
1. Never claim code works without test evidence.
2. Read files before editing.
3. Check syntax and run unit tests.
4. If a test fails, diagnose the exact failure, apply a targeted repair, and retest.
5. Create a regression test when fixing a bug.
