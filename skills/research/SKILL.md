# Research Skill

Use this skill to research concepts, ingest technical papers, query hybrid RAG, and extract grounded evidence packs.

## Rules
1. Ground all claims in retrieved evidence.
2. Maintain citations: source path, section, chunk ID, SHA-256.
3. Classify statements into FACT, EVIDENCE, INFERENCE, and UNKNOWN.
4. Detect contradictions across multiple sources.
